# 월하잔향: 백야 작전 — v2.3.2

## v2.3.2 정면 전용 패링

- 캐릭터가 바라보는 정면에서 약 16도 이내로 휘두른 발도만 탄환을 패링하거나 정확 반사할 수 있습니다.
- 위·아래·대각선·뒤쪽 발도는 적 공격 판정만 유지하며 탄환을 삭제하거나 반사하지 않습니다.
- 정면 패링 판정은 발도 시작 위치에 고정되어 낙하·상승 이동으로 범위가 늘어나지 않습니다.
- 정확 패링 시간은 0.005초로 유지됩니다.

## v2.3.1 방향 중립 패링 판정

- 탄환 패링이 적 공격용 대형 사각형을 공유하던 구조를 별도의 좁은 칼날 판정으로 분리했습니다.
- 위·아래·좌·우 어느 방향으로 발도해도 칼날 판정의 길이와 폭이 동일합니다.
- 발도를 시작한 순간의 위치와 방향에 패링 판정을 고정해 낙하·상승·대시로 탄환을 쓸어 담는 현상을 제거했습니다.
- 정확 패링 반사 시간은 기존 요청대로 0.005초를 유지합니다.

## v2.3.0 구역별 적 배치 보강

- 일반 구역마다 막에 따라 2~4기의 증원 적을 추가하고, 후반 12개 구역은 밀도를 한 단계 더 높였습니다.
- 압축 봉쇄전과 종합 봉쇄전에는 추가 증원 1기를 배치해 전투 구역이 비어 보이지 않도록 했습니다.
- 1막은 근접병과 사수 중심, 2~3막은 방패병·관통병·드론 혼합, 4~5막은 박격포와 공중 적을 포함한 복합 조합으로 구성했습니다.
- 새 적은 기존 안전 생성 지점을 재사용해 낭떠러지나 구조물 내부에 생기지 않도록 했습니다.
- v2.2.9의 구역 단위 성능 최적화를 유지해 전체 적 수가 늘어도 현재 구역 주변만 활성 계산합니다.

## v2.2.8 원본 배경 복원·점진 난이도 지형 개편

- 2.2.7에서 추가한 막별 신규 배경 실루엣을 제거하고 2.2.6의 기존 배경 연출로 되돌렸습니다.
- 맵 차별화의 중심을 배경이 아닌 실제 발판, 바닥 섬, 낭떠러지, 수직 통로, 도약 발판과 함정 배치로 옮겼습니다.
- 1막은 넓은 발판과 짧은 틈 위주의 입문형, 2막은 증기 피스톤과 복층 작업선, 3막은 상·하단이 교차하는 수직 성당으로 구성했습니다.
- 4막은 좁은 안테나 발판과 연속 수직 레이저, 5막은 끊어진 바닥 섬·비대칭 거울 계단·레이저와 가시가 겹치는 최고 난도로 구성했습니다.
- 같은 막 안에서도 6구역마다 함정 밀도와 간격이 한 단계씩 증가해 뒤쪽 구역으로 갈수록 어려워집니다.
- 튜토리얼, 홍련의 단층 보스전, 중간보스·진보스 전용 경기장과 초기 화면 밖 적 정리 기능은 유지됩니다.

## v2.2.7 5막 고유 맵 전면 개편

- 1막은 크레인과 전자석, 기울어진 폐선 잔해를 갈아타는 **백야 크레인 묘지**로 바뀌었습니다.
- 2막은 낮은 제련 라인과 박자가 다른 증기 피스톤을 돌파하는 **적열 피스톤 제련소**로 바뀌었습니다.
- 3막은 부유 제단과 도약 장치를 타고 수직으로 오르는 **기억 대성당**으로 바뀌었습니다.
- 4막은 폭풍 속 안테나와 열린 도시 외벽을 지그재그로 등반하는 **폭풍 안테나 첨탑**으로 바뀌었습니다.
- 5막은 위·아래 길이 어긋나며 접히는 **원형 거울 미궁**으로 바뀌었습니다.
- 각 막에 전용 지형 템플릿을 추가하고 기존 120개 구역의 배치를 재구성해 같은 구조의 반복을 크게 줄였습니다.
- 배경도 막별로 크레인·용광로·성당 아치·송신탑·복제 캡슐 실루엣과 서로 다른 환경 입자를 사용합니다.
- 홍련 보스전의 단층 평지, 기존 중간보스·진보스 전용 경기장, 관리자 월드 편집 데이터 호환은 유지됩니다.

## v2.1.7 정확 발도 패링

- 기존 발도는 이전처럼 적 탄환을 지우며, 발도 유효 판정이 시작된 뒤 0.055초 안에 맞춘 탄환은 정확 패링으로 판정합니다.
- 정확 패링한 탄환은 원래 진행 방향의 정반대로 되돌아가 적에게 기존 탄환 위력만큼 피해를 줍니다.
- 반사탄은 최소 속도 560과 기존 속도의 1.25배 중 높은 값을 사용해 공격한 적에게 빠르게 돌아갑니다.
- 빔·독가스·마법진처럼 피해 장판이나 공격 예고 역할을 하는 오브젝트는 반사되지 않고 기존처럼 발도로 삭제됩니다.
- 정확 패링 성공 시 청백색 반사탄, 원형 섬광, 전용 타격음과 짧은 정지 효과가 표시됩니다.
- 일반 적 회복 아이템은 기존 7킬마다 1회 생성되던 방식에서 개별 처치당 6% 확률로 낮췄으며, 보스 소환물과 관리자 삭제 대상은 드롭하지 않습니다.

## GitHub에 올리기

이 폴더의 **내용물**을 저장소 루트로 사용하세요. 저장소 첫 화면에서 `index.html`, `game.js`, `VERSION.txt`, `.github`가 바로 보여야 합니다. 별도 배포 폴더 안에 한 단계 더 들어가면 GitHub Pages는 이전 루트 파일을 계속 배포합니다.

GitHub 웹 업로드를 사용할 때는 배포용 ZIP을 먼저 압축 해제한 뒤, 생긴 파일과 폴더를 전부 저장소 루트에 올리세요. ZIP 파일 자체나 ZIP을 감싸는 상위 폴더를 올리면 안 됩니다.

GitHub에서 빈 저장소를 만든 뒤 명령으로 올릴 때는 아래와 같이 실행합니다.

```powershell
git init
git add .
git commit -m "Initial release"
git branch -M main
git remote add origin https://github.com/사용자명/저장소명.git
git push -u origin main
```

저장소의 `Settings → Pages → Build and deployment → Source`를 `GitHub Actions`로 선택하면 `main` 브랜치에 푸시할 때 게임이 자동 배포됩니다. 배포 주소는 Actions의 `Deploy GitHub Pages` 작업에서 확인할 수 있습니다.

업데이트 확인은 배포 주소 끝에 `/VERSION.txt`를 붙여 접속하세요. `2.2.6`가 보이면 새 루트가 정상 배포된 것입니다. Actions 작업이 끝나기 전에 새로고침하거나 Pages Source가 `Deploy from a branch`로 남아 있으면 이전 버전이 보일 수 있습니다.

로컬 실행과 문법 검사는 다음 명령으로 할 수 있습니다.

```powershell
npm.cmd start
npm.cmd test
```

## 조작

- `A`, `D`: 이동
- `Space`: 점프 / 이중 점프 / 벽차기
- 마우스 이동: 조준
- 마우스 왼쪽: 캐릭터가 바라보는 방향으로 발도술. 발도 범위 안의 적 총알을 쳐낼 수 있음
- 마우스 오른쪽: 샷건. 공중에서 아래로 발사하면 반동으로 상승
- `F` 또는 `C`: 키보드 샷건 보조 입력
- `J` 또는 `X`: 키보드 발도 보조 입력
- `E`: 주변 탄환을 소거하는 버스트
- `R`: 일반 작전은 마지막 체크포인트 복귀, 관리자 작전은 신참내기 실전 모드 전환/복귀
- 관리자 `L`: 5개 스테이지의 전체 120구역 이동창
- 관리자 `Space` / `Shift`: 상승 / 하강, 벽 통과 공중 이동
- `Esc`: 일시정지

## 전투 순환

발도술을 적중시키거나 적 탄환을 베면 샷건 강화 게이지가 충전됩니다. 3칸이 가득 찬 상태에서 발사하면 강화 샷건이 나가며 방패를 관통하고 넓은 범위에 큰 피해를 줍니다.

샷건은 두 발을 순차 재장전합니다. 공중에서 아래쪽을 조준해 발사하면 반동으로 다시 상승하고, 수평으로 발사하면 반대 방향으로 빠르게 밀려납니다. 이중 점프를 사용한 뒤 공중 발도를 맞히면 추가 점프가 돌아옵니다.
