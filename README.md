## v3.6.9 실녹음 점프음·보스 대포음

- 지상 점프, 벽점프, 이중 점프에 CC0 점프 폴리 녹음을 적용하고 동작별 음량과 재생 속도를 분리했습니다.
- 보스의 실탄 사격은 일반 적의 권총·소총음과 구분되는 묵직한 CC0 대포 발사음으로 교체했습니다.
- 다발 패턴의 대포음은 150ms 중첩 제한을 적용해 한 번의 공격에서 포성이 과도하게 겹치지 않습니다.
- 마법탄과 위상탄은 기존 전자·마법 효과음을 유지하고, 일반 포탑은 기존 소총음을 유지합니다.
- 기본 BGM은 일반 구역 17%, 보스 26%, 타이틀 20%, 컷신 10%로 한 단계 높였습니다.
- 보스 구역에 진입하면 입장 대화부터 보스 처치까지 화면에 보이는 양쪽 봉쇄선이 플레이어를 가두며, 보스가 죽은 뒤에만 해제됩니다.

## v3.6.8 실녹음 전투·이동 효과음과 음량 설정

- 샷건 발사음과 펌프 작동음, 적 권총·소총음을 실제 녹음 기반 CC0 음원으로 교체해 무장별 충격과 기계 작동음을 분리했습니다.
- 콘크리트 보행 녹음 6종을 걷기·달리기 속도와 막에 따라 번갈아 재생해 발걸음의 반복감을 줄였습니다.
- `ESC` 일시 정지 화면에서 전체·배경 음악·효과음 음량을 각각 조절하고 음소거할 수 있으며 설정은 브라우저에 저장됩니다.
- 기본 BGM 음량은 일반 구역 13%, 보스 22%, 사용자 초기 음악 음량 52%로 낮춰 전투 효과음이 묻히지 않게 했습니다.
- 사용한 외부 효과음의 원본·저작자·CC0 라이선스를 `THIRD_PARTY_ASSETS.md`에 기록했습니다.

## GitHub에 올리기

이 폴더의 **내용물**을 저장소 루트로 사용하세요. 저장소 첫 화면에서 `index.html`, `game.js`, `VERSION.txt`, `.github`가 바로 보여야 합니다. 별도 배포 폴더 안에 한 단계 더 들어가면 GitHub Pages는 이전 루트 파일을 계속 배포합니다.

GitHub 웹 업로드를 사용할 때는 배포용 ZIP을 먼저 압축 해제한 뒤, 생긴 파일과 폴더를 전부 저장소 루트에 올리세요. ZIP 파일 자체나 ZIP을 감싸는 상위 폴더를 올리면 안 됩니다.

GitHub에서 빈 저장소를 만든 뒤 명령으로 올릴 때는 아래와 같이 실행합니다.

```powershell
git init
git add .
git commit -m "Initial release"
git branch -M main
git remote add origin https://github.com/사용자명/저장소명.git
git push -u origin main
```

저장소의 `Settings → Pages → Build and deployment → Source`를 `GitHub Actions`로 선택하면 `main` 브랜치에 푸시할 때 게임이 자동 배포됩니다. 배포 주소는 Actions의 `Deploy GitHub Pages` 작업에서 확인할 수 있습니다.

업데이트 확인은 배포 주소 끝에 `/VERSION.txt`를 붙여 접속하세요. `2.2.6`가 보이면 새 루트가 정상 배포된 것입니다. Actions 작업이 끝나기 전에 새로고침하거나 Pages Source가 `Deploy from a branch`로 남아 있으면 이전 버전이 보일 수 있습니다.

로컬 실행과 문법 검사는 다음 명령으로 할 수 있습니다.

```powershell
npm.cmd start
```

## 조작

- `A`, `D`: 이동
- `Space`: 점프 / 이중 점프 / 벽차기
- 마우스 이동: 조준
- 마우스 왼쪽: 캐릭터가 바라보는 방향으로 발도술. 칼날에 닿은 투사체와 대역-13의 플라스크·독가스 제거 가능
- 마우스 오른쪽: 샷건. 공중에서 아래로 발사하면 반동으로 상승
- `F` 또는 `C`: 키보드 샷건 보조 입력
- `J` 또는 `X`: 키보드 발도 보조 입력
- `E`: 주변 탄환을 소거할 수 있는 유일한 방어 기술인 버스트
- `R`: 관리자 작전에서만 현재 위치 기준 신참내기 실전 모드 전환/복귀. 일반 작전에서는 사용하지 않음
- 관리자 `L`: 5개 스테이지의 전체 80구역 이동창
- 관리자 `Space` / `Shift`: 상승 / 하강, 벽 통과 공중 이동
- `Esc`: 일시정지

발도술을 적이나 투사체에 적중시키면 샷건 강화 게이지가 충전됩니다. 3칸이 가득 찬 상태에서 발사하면 강화 샷건이 나가며 방패를 관통하고 넓은 범위에 큰 피해를 줍니다. 버스트는 주변 탄환을 한꺼번에 지우고, 발도는 칼날에 직접 닿은 투사체만 제거합니다. 대역-13의 변이 바닥 파편은 두 기술 중 버스트로만 제거할 수 있습니다.

샷건은 두 발을 순차 재장전합니다. 공중에서 아래쪽을 조준해 발사하면 반동으로 다시 상승하고, 수평으로 발사하면 반대 방향으로 빠르게 밀려납니다. 이중 점프를 사용한 뒤 공중 발도를 맞히면 추가 점프가 돌아옵니다.
